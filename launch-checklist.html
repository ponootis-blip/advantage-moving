Point advantagemovingaustin.com at the new site

Launch
Assumed: The business owns advantagemovingaustin.com, the old website lives there today, and the new site should replace it. Company email (service@…) also uses this domain and must keep working.
  1. In GitHub, open Pages settings and type advantagemovingaustin.com as the custom domain. Verify the domain first if GitHub asks.
  2. At the domain registrar (wherever the domain was bought), add four A records for the bare domain: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
  3. Add a CNAME record: www → ponootis-blip.github.io.
  4. Do not change MX or TXT records—those run your email.
  5. When GitHub shows the certificate is ready (can take up to 24 hours), tick Enforce HTTPS.
  6. In Formspree, change the allowed domain to advantagemovingaustin.com, then send one more test quote.

  • Verify domain in GitHub ↗
  • Check DNS has updated ↗
If this is wrong
  • The site should live on a different domain: replace advantagemovingaustin.com in every file’s “canonical” and “og:url” tags, plus sitemap.xml and robots.txt.
  • The old site had pages with other addresses that people bookmarked: list them so they can be mapped to the new pages.
